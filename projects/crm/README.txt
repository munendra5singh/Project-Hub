PROPERTY MANAGER PRO
====================

Open index.html in Chrome/Edge/Firefox. No server, Firebase, or internet is required.

Included:
- Responsive dashboard
- 28 demo properties pre-filled
- Add / Edit / Delete
- Search across property data
- Location/type/status filters
- Sorting
- Table + card view
- Favorites
- Follow-up dates
- Call / WhatsApp / Google Maps / Video links
- Notes
- Upcoming Projects section (Economical, Mid-Premium, Luxury)
- Auto-determined Price Categories & Budget Slabs
- Status tracking: Upcoming, Pre-Launch, Launched, Ready
- Dashboard summary & recent projects
- Responsive table & card views for both Properties and Upcoming Projects
- JSON backup/restore (unified support for Properties & Upcoming Projects)
- LocalStorage persistence (isolated storage keys)
- Mobile/tablet/desktop responsive UI

Data keys:
- Properties: property_manager_pro_v2
- Upcoming Projects: property_manager_pro_v2_upcoming

Tip: Use Ctrl/Cmd + K to jump to search.

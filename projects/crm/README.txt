PROPERTY MANAGER PRO
====================

Open index.html in Chrome/Edge/Firefox. No server, Firebase, or internet is required.

Included:
- Responsive dashboard
- 28 demo properties pre-filled
- Add / Edit / Delete
- Search across property data
- Location/type/status filters
- Sorting
- Table + card view
- Favorites
- Follow-up dates
- Call / WhatsApp / Google Maps / Video links
- Notes
- JSON backup/restore
- LocalStorage persistence
- Mobile/tablet/desktop responsive UI

Data key: property_manager_pro_v2

Tip: Use Ctrl/Cmd + K to jump to property search.

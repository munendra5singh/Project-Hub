# ⚡ Project Hub | Developer Dashboard

A modern, fast, and responsive **Developer Dashboard** designed to organize, search, and launch all your web projects, tools, AI applications, and templates from a centralized interface.

🔗 **Live Demo:** munendra5singh.github.io/Project-Hub

---

## 🌟 Key Features

* **Multi-View Navigation:** Filter projects by *All*, *Favorites*, *Recently Opened*, *Search*, and *Categories*.
* **Dynamic Search & Filtering:** Instant keyword search across project titles, tech stacks, and tags with zero reload.
* **Layout Switcher:** Toggle smoothly between **Grid View** and **List View** based on preference.
* **Sorting Engine:** Sort projects alphabetically (A–Z or Z–A) on the fly.
* **Theme Switching:** Built-in dark and light aesthetic support with custom ambient background glow.
* **Responsive & Mobile-First:**
  * Clean desktop sidebar with quick access cards.
  * YouTube-style fixed bottom navigation bar on mobile devices.
* **Data-Driven Architecture:** Project details are managed centrally via `projects.js` for easy updates.

---

## 🛠️ Built With

* **HTML5:** Semantic markup, comprehensive SEO, and Open Graph / Twitter Card tags.
* **CSS3:** Custom properties (CSS variables), glassmorphism effects, flexbox/grid layout, and smooth transitions.
* **Vanilla JavaScript:** Fast client-side DOM manipulation, filtering, sorting, and state handling.
* **Typography:** [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) & [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono).
